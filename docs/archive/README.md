# Archive

Historical records of finished work. They are not maintained and do not describe current behavior; use [`../README.md`](../README.md) and [`../../audit/`](../../audit/README.md) for that.

| Folder | Contents |
|---|---|
| `reports/` | Per-feature implementation, QA and audit reports, checkpoints and dry runs |
| `manual-apply/` | One-off notes and SQL for applying a single migration by hand (0025–0036 and profile role immutability). The two `blueprint-library-0031-*.sql` files stay in `docs/` because a smoke script reads them |
| `clean-supabase/` | Reports from bringing up and rehearsing the clean Supabase project |

Inside these files, paths written as `docs/<name>` refer to the folder layout at the time they were written; the files now live under `docs/archive/<folder>/`. Relative markdown links were updated when the files moved.
